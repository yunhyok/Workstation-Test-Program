# 실행 실패 이후의 후속 과제 — 2026-09-30

## 판단 근거

사용자가 제공한 실행 스냅샷에서 환경·내장 엔진 검사와 P9 비교는 통과했다. 두 설계의 184개 포트에 대한 P92 CPU/GPU 비교는 25개, GPU 반복 비교는 20개가 허용치 `1e-8`을 초과했다. 최대 상대오차는 각각 약 `4.01e-6`, `8.39e-7`이다. 계산 작업 실패는 없었으나 배치가 수치 비교 실패 직후 멈춰 자원 조건과 수렴성 검증이 실행되지 않았다. 재실행 P9는 기존 결과를 재사용했다.

이 사실로 GPU 하드웨어 고장이나 수치 오차의 내부 원인을 확정하지 않는다. 원본 설계·포트 이름과 실행 데이터는 공개 저장소에 올리지 않는다.

## 선정한 과제와 완료 기준

|---|---|---|---|
| P0 | 독립 단계 계속 실행 | 기준선 비교 실패 뒤에도 B/C/D/E와 F 실행. 필수 환경·게이트 실패 시 종속 측정은 건너뜀. 실패·건너뜀의 이유와 전체 실패 상태 보존. 사용자 중단은 즉시 후속 실험 차단 | 1.3.0 구현 |

P1에서 필요하다면 보정 횟수 등 수치 실험을 별도 작업 폴더에서 수행한다. 그 실험을 기존 고정 설정의 합격 결과로 섞지 않는다. 확인된 원인에 대한 수정 후에는 실패 집합과 통과 대조군을 먼저 재검증하고, 통과하면 전체 P92와 관련 자원 조건을 검증한다. 임의의 허용오차 완화나 GPU의 조용한 CPU 대체는 해결책으로 인정하지 않는다.

## 단계의 의존 관계

| 단계 | 필수 선행 조건 | 앞선 기준선 합격 필요 여부 |
|---|---|---|
| env | 설정과 실행 환경 | 없음 |
| gates | env 성공 | 없음 |
| baseline P9/P92 | 유효한 gates와 현재 입력·환경 일치 | 서로 독립 |
| matrix B/C/D/E | 유효한 gates; 축별 참조 계산은 자체 수행 | 없음 |
| converge F | 유효한 gates; 격자 비교 계산은 자체 수행 | 없음 |
| report | 읽을 수 있는 결과와 보고서 실행 환경 | 실패·미완료 결과도 생성 시도 |
| ZIP | 읽을 수 있는 결과 작업 폴더 | 엔진과 측정 합격 불필요 |

전체 배치는 이 관계에 따라 건너뛴 단계를 명시한다. 단계별 실행은 기존 입력·환경 검사를 계속 수행한다. 중단 요청은 오류와 구분하며 다음 실험을 시작하지 않는다. 오류 뒤에 계속 실행해도 최종 결과를 전체 합격으로 바꾸지 않는다.

## 운영 순서

1. 기존 실패 결과를 ZIP으로 보존한다.
2. 1.3.0에서 같은 작업 폴더를 지정하고 전체 또는 필요한 단계의 실행을 재개한다. 동일한 완료 영수증은 재사용하므로 기존 기준선 비교 실패가 다시 나타날 수 있지만 독립된 후속 실험은 진행한다.
3. 종료 후 `exports`의 ZIP으로 실행 범위와 실패를 검토한다.
4. 수치 오차 원인은 P1의 새 계산으로 조사한다. 전체 실행을 같은 조건으로 반복하는 것만으로 해결되었다고 판단하지 않는다.

이 계획은 후속 실행과 진단을 위한 문서다. 기존 `W15_PLAN_20260921.md`의 사전 등록, 수학 옵션, 허용오차와 측정 정의를 변경하지 않는다.
