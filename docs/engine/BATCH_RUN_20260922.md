# Sequential experiment controls — 1.1.0 candidate

The GUI now provides **전체 실험 순차 실행 / 재개** and
**선택 단계의 모든 조건 실행 / 재개**. The full plan has ten ordered stages:
env, gates, baseline P9, baseline P92, matrix B/P9, C/P92, D/P92, E/P20,
converge/P92, and report. Stage selection filters this same plan. The table shows
pending, running, completed, failed, and stopped states. Manual execution remains
available with its selected port set and axis.

`validate batch --stage all` uses existing numerical handlers under one campaign
lock. Existing identities and completed receipts govern measurement reuse; a
previous batch's completed flags never bypass env/gates. Nonzero exits, exceptions,
and stop requests halt the queue. The current stage's logs and immutable summary
are separate from the campaign summary. A diagnostic env result without an engine
connection cannot be treated as a successful batch stage.
