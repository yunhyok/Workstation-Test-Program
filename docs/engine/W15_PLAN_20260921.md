## 환경과 실행 순서

Python 3.12.10, numpy 2.4.4, scipy 1.18.0 및 소유자의 laptop_pip_freeze_system_python.txt를
기준으로 버전 차이를 먼저 기록한다. 실제 CPU/RAM/GPU를 탐지하고 WORKSTATION 합성
프로필과 구별한다. 대상은 Threadripper 32C/64T, 512 GB, A6000이며 VRAM은 탐지값이다.
현재 개발 노트북의 검사 결과를 워크스테이션 실측으로 취급하지 않는다.

측정 전에 외부 엔진 저장소에서 다음 세 게이트가 실제 데이터를 사용해 통과해야 한다.
데이터 또는 GPU 부재로 필요한 재현 테스트가 건너뛰어지면 미검증이다.

1. `python -m pytest tests/engine -q`
2. `python -m pytest tests/engine -q --gpu`
3. `python -m pytest tests/engine -q --slow`

실행·영수증·로그는 SPD_PI_WORK_DIR/w15 또는 사용자가 고른 외부 작업 폴더에 저장한다.
기존 결과는 덮어쓰지 않는다. 상태 파일은 가변 최신 상태이며 영수증은 불변 기록이다.
원본 SPD, Touchstone, 참조 NPZ, 노트북 영수증, 토큰과 개인 설정은 공개하지 않는다.

## 입력과 고정 옵션

P9: 260729 Port1/7/14/16/18/19_SITE0, 260804 Port18_SITE0,
s5m6585 Port1_U1_0/Port50_U1_0. P92는 260729 전체 92포트다.
20포트 부분집합은 원본 SPD 순서와 가장 큰 Port49를 포함하는 결정적 선택으로 고정한다.
주파수는 ladder_freqs 27점, FLAGS_P, powersi-compatible,
h=200, fh=50, top_h=50, sub=(20,10,10), fringe=True를 사용한다.
다른 SPD는 별도 설계 manifest로 입력하며 held-out으로 취급한다.

RAM/VRAM 가짜 프로필은 플래너 에뮬레이션이다. OS 메모리 상한이 아니다.
공용 GPU의 memory.used는 장치 전체 표본이므로 다른 앱과 컨텍스트의 기여를 포함한다.
프로세스당 VRAM은 추정량으로 명시한다. 동시 RSS는 관측 구간이 겹친 worker의 합으로 계산한다.
원본 Touchstone 변환은 제품 read_touchstone/s_to_z/라벨 변환기를 사용한다.
기존 NPZ와 rtol=1e-12 검증하며 원본 부재 시 합성 2포트 자기검사만 하고 미검증으로 기록한다.

## 중단·재개와 실패

포트/케이스 경계마다 stop-file을 확인한다. graceful은 실행 중 포트를 기다린다.
엔진 내부 주파수 사이에는 중단 콜백이 없으며 즉시 중단은 전체 프로세스 트리 종료다.
10초 heartbeat와 stopped_at을 기록한다. 완성되고 입력 신원이 일치하는 영수증만 재사용한다.
게이트 실패·누락, numerics_id/주파수/설계 불일치는 PASS로 숨기지 않는다.
예측이 빗나가도 그대로 보고하고 엔진 결함은 엔진 요구사항에 적는다.
